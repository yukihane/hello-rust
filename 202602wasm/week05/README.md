# Week 5: サイズ最適化

## 目標
- release ビルドサイズを計測する
- 最適化前後の差分を数値で説明できる

## 演習案
- 関数追加前後で `pkg/*.wasm` サイズを比較する

## 進め方（具体ステップ）
1. baseline を作る
   - `wasm-pack build --target web --release`
   - `ls -lh pkg/*.wasm` でサイズ記録
2. 機能追加後に再ビルドし、サイズを再計測する
3. 不要な公開関数や依存を削減して再計測する
4. 結果を `before/after` で README に残す

## 動作確認
- 最適化後も `http://localhost:8000/web/` で機能が壊れていない

## 完了条件
- サイズ比較表（最低2パターン）がある
- サイズを増やした要因/減らした要因を説明できる
