# Week 4: テストとデバッグ

## 目標
- `wasm-bindgen-test` を導入する
- エラー時の挙動を確認できるようにする

## 演習案
- 公開関数に単体テストを追加する
- 失敗パターンの動作を確認する

## 進め方（具体ステップ）
1. `Cargo.toml` に `wasm-bindgen-test` を追加する
2. `src/lib.rs` にテストモジュールを追加する
   - 正常系を2件以上
   - 異常系を1件以上
3. テストを実行する
   - `wasm-pack test --node`
4. エラー返却関数（`Result<_, JsValue>`）の失敗時表示を JS 側で確認する
5. panic が起きたときに、どこで失敗したかログを読めることを確認する

## 動作確認
- `wasm-pack test --node` が成功
- ブラウザ上で失敗時メッセージが表示される

## 完了条件
- テストが自動実行できる
- 正常系/異常系の最低限の回帰確認ができる
