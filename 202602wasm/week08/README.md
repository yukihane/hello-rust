# Week 8: 実践プロジェクト

## 目標
- テストあり・配布可能な小規模プロジェクトを完成させる

## 演習案
- これまでの成果を1つのリポジトリに統合する

## 進め方（具体ステップ）
1. テーマを1つ決める
   - 例: テキスト整形、簡易パーサ、数値計算ツール
2. 最小要件を決める
   - 必須機能3つ
   - テスト3件
3. 実装する
   - API公開
   - UI連携
   - エラーハンドリング
4. 品質を固める
   - `clippy` / テスト
   - サイズ確認
5. 成果物としてまとめる
   - 使い方
   - 制約
   - 今後の改善案

## 動作確認
- 新規環境で README の手順だけで起動できる

## 完了条件
- 機能・テスト・実行手順が揃っている
- 他人が触って動かせる状態になっている
