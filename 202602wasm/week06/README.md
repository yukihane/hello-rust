# Week 6: フレームワーク入門

## 目標
- Leptos / Yew / Dioxus のどれか1つで小規模アプリを作る

## 演習案
- TODO かメモアプリを1つ作る

## 進め方（具体ステップ）
1. フレームワークを1つ選ぶ（迷ったら Yew か Leptos）
2. 新規プロジェクトを `week06/` に作る
3. 最小画面を作成する
   - 入力欄
   - 追加ボタン
   - 一覧表示
4. 状態管理を実装する
   - 追加
   - 削除
   - 完了切替（任意）
5. ルーティングまたはフィルタ機能を1つ追加する

## 動作確認
- ビルドが通る
- 画面上で追加/削除ができる

## 完了条件
- 単一ページで最低1つの状態遷移が実装できている
- README に起動手順が書かれている
